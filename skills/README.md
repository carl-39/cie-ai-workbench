# Skills

Skills encode reusable specialist workflows, methods and quality controls. They describe how to carry out a capability reliably, including what to do when information is missing or confidence is low.

Each skill uses a `SKILL.md` primary file to support future ChatGPT/Codex-style packaging. Copy [`_template/SKILL.md`](_template/SKILL.md) into a descriptive kebab-case directory. Add only the supporting references, examples or tests the skill actually needs.

## Available skills

- [Academic writing coach](academic-writing-coach/SKILL.md) — guides social-science writers through practice and developmental feedback while preserving authorship.
- [Fabricated reference detector](fabricated-reference-detector/SKILL.md) — audits references cautiously without turning negative searches into misconduct findings.
- [Identify source type](identify-source-type/SKILL.md) — classifies publication form and version for APA 7 referencing without overstating certainty.
- [OpenAlex researcher](openalex-researcher/SKILL.md) — discovers, maps, appraises and synthesises scholarly literature using bounded OpenAlex searches.
- [Prompt engineering](prompt-engineering/SKILL.md) — designs and reviews reusable prompts with explicit inputs, outputs and verification.
- [Table and figure assistant](table-and-figure-assistant/SKILL.md) — creates and reviews APA 7 tables, figures, attribution and assignment integration.
- [Teach APA 7 microlearning](teach-apa7-microlearning/SKILL.md) — teaches one APA 7 convention at a time through adaptive practice and mastery checks.
- [Verify source metadata](verify-source-metadata/SKILL.md) — extracts bibliographic metadata and verifies material fields against authoritative records.
