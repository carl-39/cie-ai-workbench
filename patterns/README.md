# Patterns

Patterns document reusable ways for people and AI to work together. A pattern covers the full practice: problem, context, division of responsibility, workflow, verification and failure modes. It may reference prompts, skills and agents without collapsing those assets into one concept.

Copy [`_template/README.md`](_template/README.md) into a descriptive kebab-case directory.

## Available patterns

- [Verified research synthesis](verified-research-synthesis/README.md) — combines human source selection and verification with AI-assisted thematic synthesis.
