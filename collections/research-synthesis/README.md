# Research synthesis

This collection brings together the current assets for producing a structured, traceable synthesis from a bounded set of supplied research material.

All listed assets are experimental. The responsible person must evaluate the source set and verify substantive claims against the original material.

## Suggested route

1. Use [OpenAlex researcher](../../skills/openalex-researcher/SKILL.md) for non-exhaustive scholarly discovery when a source set has not already been supplied.
2. Use the [Source evaluation collection](../source-evaluation/README.md) to classify source types and verify retained records where needed.
3. Apply the [Research synthesis prompt](../../prompts/research-synthesis/README.md) to organise labelled source material around a defined question.
4. Follow the [Verified research synthesis pattern](../../patterns/verified-research-synthesis/README.md) when the complete human–AI workflow, responsibilities and verification record matter.

## Assets in this collection

| Asset | Type | Role in the work |
| --- | --- | --- |
| [OpenAlex researcher](../../skills/openalex-researcher/SKILL.md) | Skill | Supports bounded literature discovery, appraisal, evidence mapping and bibliometric analysis. |
| [Research synthesis](../../prompts/research-synthesis/README.md) | Prompt | Produces a thematic synthesis and verification table from supplied material. |
| [Identify source type](../../skills/identify-source-type/SKILL.md) | Skill | Classifies likely source types from observable evidence while showing uncertainty. |
| [Verified research synthesis](../../patterns/verified-research-synthesis/README.md) | Pattern | Assigns responsibilities across source selection, AI-assisted synthesis and human verification. |

## Important boundary

This collection supports discovery and synthesis of a bounded source set. OpenAlex alone is not exhaustive and does not establish peer review or study quality. The collection does not by itself define a systematic literature review method or make the final decision that an output is fit for use.
