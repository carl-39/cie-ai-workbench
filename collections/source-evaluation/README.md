# Source evaluation

This function collection helps users discover scholarly records, identify source types, verify bibliographic metadata and audit references without overstating negative search results.

## Suggested route

1. Use [OpenAlex researcher](../../skills/openalex-researcher/SKILL.md) when scholarly discovery, citation mapping or bounded bibliometric analysis is needed.
2. Apply [Identify source type](../../skills/identify-source-type/SKILL.md) to classify publication format from observable evidence.
3. Use [Verify source metadata](../../skills/verify-source-metadata/SKILL.md) to preserve extracted values and verify material fields against authoritative records.
4. Apply [Fabricated reference detector](../../skills/fabricated-reference-detector/SKILL.md) when a reference or citation list needs a cautious evidence-based audit.
5. Continue to the [Research synthesis collection](../research-synthesis/README.md) when verified sources will feed into a bounded synthesis workflow.
6. Check the [quality standards](../../docs/quality-standards.md) before using any result in consequential work.

## Important boundary

Source type, metadata accuracy, retrievability, research quality and relevance are distinct judgements. Reference-audit classifications are not automatic evidence of misconduct and must not be converted into allegations without appropriate human review and institutional process. OpenAlex coverage is not exhaustive, and citation prominence is not a quality measure.
