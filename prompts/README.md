# Prompts

Prompts are reusable instructions for an AI tool. They specify a task, useful context, inputs, expected output and checks. They should not conceal a larger multi-step practice that is better represented as a skill or pattern.

Copy [`_template/README.md`](_template/README.md) into a descriptive kebab-case directory. Complete only relevant optional sections. Record model-specific assumptions when portability is limited.
